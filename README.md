CampusBuzz
CampusBuzz is a college event management system developed using Python with Tkinter and SQLite.

Features
1.Admin Dashboard to add, edit, and view events.
2.Student Dashboard to view events, register for them, and check their registrations.
3.Simulated payment feature for event registration.
4.User-friendly interface created using Tkinter.
5.Local data management using SQLite database.

Technology Stack
Frontend: Tkinter (Python GUI)
Backend: Python
Database: SQLite
Libraries Used: PIL, Tkinter, sqlite3, subprocess, os
